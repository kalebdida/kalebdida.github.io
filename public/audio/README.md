# Celebration recording

`ronaldo-siuuu.mp3` is the short Cristiano Ronaldo "Siuuu" recording supplied in
[luizrioga/Siuuu](https://github.com/luizrioga/Siuuu/blob/49da1f9423f3a916f5ac3f1620d1c4edda6d5376/siuuu.mp3).

The audio is stored locally and plays only after the football button is pressed.
It is a recording, with no speech synthesis or voice generation. The source
repository's MIT license is included in `SOURCE-LICENSE.txt`.
